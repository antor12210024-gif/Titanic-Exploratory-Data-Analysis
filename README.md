# Titanic Exploratory Data Analysis

## 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on the Titanic dataset using Python.

## 🛠 Technologies Used
- Python
- Pandas
- Matplotlib

## 📂 Dataset
Titanic Dataset

## 📊 Analysis Performed
- Data Cleaning
- Missing Value Analysis
- Summary Statistics
- Survival Analysis
- Gender Distribution
- Passenger Class Distribution
- Correlation Matrix

## 🚀 How to Run

```bash
pip install -r requirements.txt
python eda.py
```

## 📈 Output
The project generates statistical summaries and visualizations for the Titanic dataset.
